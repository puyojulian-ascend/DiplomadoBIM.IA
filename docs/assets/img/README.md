# Imágenes de las sesiones

Poné acá los archivos de imagen que uses en las presentaciones
(`.png`, `.jpg`, `.svg`, `.webp`, `.gif`).

Desde un archivo de sesión (`docs/sessions/NN-*.md`) se referencian con **ruta
relativa desde la raíz del sitio**, así:

```markdown
![Texto alternativo](assets/img/mi-imagen.png)
```

Sugerencias:
- Nombres en minúsculas, sin espacios ni tildes: `diagrama-flujo.png`.
- Podés organizar por sesión con subcarpetas: `assets/img/05/portada.png`.
- Optimizá el peso (idealmente < 500 KB) para que el deck cargue rápido.
- También podés usar una **URL externa** (`https://…`) en vez de un archivo local.
